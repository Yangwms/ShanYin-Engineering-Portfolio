# 天貓顧客回購預測

**碩士學位論文**

260,864 筆樣本 · 32 項特徵

[返回作品集首頁](../../README.md)

## 技術與工具

CGAN / XGBoost / ROS / SMOTE / ADASYN

## 研究問題

以天貓電商顧客是否回購建立二元分類任務，探討不平衡資料處理與生成模型搭配後對預測流程的影響。正式學位論文為「整合生成模型與不平衡資料處理方法之電商顧客回購預測：以天貓資料集為例」。

## 資料與實驗流程

前處理後取得 260,864 筆樣本，將顧客行為轉換為 32 項模型特徵。比較原始資料、隨機過採樣 ROS、SMOTE 及 ADASYN 四種設定，再結合 CGAN 估計資料分布，以 XGBoost 建立分類模型。

## 驗證設計

使用三折交叉驗證，並納入「過採樣後直接使用 XGBoost」的對照設定，檢視加入生成模型前後的差異。作品集呈現研究方法與資料規模；沒有可核對的完整指標表時，不將方法使用等同於準確率提升。

## 履歷重點

- 以天貓電商資料建構是否回購的二元分類任務，完成資料前處理，將顧客行為紀錄轉換為 32 項模型訓練特徵。

- 比較原始資料、ROS、SMOTE 與 ADASYN 四種設定，結合 CGAN 估計資料分布，再以 XGBoost 建立回購預測模型。

- 採用 3-fold 交叉驗證，並納入過採樣後直接使用 XGBoost 的對照設定，檢視加入生成模型前後的差異。
