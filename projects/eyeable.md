# EyeAble 智慧眼控介面

**USR 跨域工作營 · 第四組**

> 金秀獎 · 54 小時工作營

## 專案內容

- 參與實踐大學「科技生活設計跨領域大工作營（一）之智慧照護設計」，與跨領域團隊共同提出 EyeAble 眼控介面設計。

- 團隊針對無法以口語或肢體表達的使用者，提出放大選取區域、增加間距、九宮格鍵盤及直覺頁面切換等設計。

- 成果涵蓋常用語、緊急呼叫與個人助理概念，完成海報及專刊展示，團隊於 2025/11/19 獲金秀獎；個人完成 54 小時工作營。

## 技術

Accessibility / UX / Eye-tracking Interface / iPadOS

## 結果與範圍

以團隊設計提案及成果展示呈現；AI 個人助理屬方案功能構想，未宣稱已完成可部署 AI 系統或臨床成效驗證。

團隊成員；金秀獎與工作營參與證均載有楊善茵姓名。
