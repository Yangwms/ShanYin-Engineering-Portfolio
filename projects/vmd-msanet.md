# 台股預測與策略回測

**VMD-MSANet · 聯發科 2454.TW**

> 16 個 VMD 特徵 · V2 / V3 迭代

## 專案內容

- 串接資料擷取、特徵建構、模型訓練與逐日滾動回測；整合 2018 年起個股、市場指數與匯率資料。

- 以 5／10／20／30 日尺度各分解 4 個 IMF，建立 16 個 VMD 特徵，並處理 vmdpy 序列長度對齊問題。

- V3 改採未來五日報酬率與上漲機率雙任務，加入技術指標與驗證集門檻搜尋；研究回測報酬由 29.54% 增至 43.04%，最大回撤由 −19.13% 改善至 −15.32%。

## 技術

Python / yfinance / vmdpy / Attention / Multi-task Learning

## 結果與範圍

回測自 2025/01 起，既有簡報資料截至 2026/06；V2／V3 為 344／343 個交易日。訊號變化時扣 0.1425% 設定成本。V3 Sharpe 1.21、方向準確率 48.10%，仍落後同期大盤及 0050；非實際投資獲利。

研究報告與模型比較成果；本作品集未附可重跑的原始程式與模型權重。
