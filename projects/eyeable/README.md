## 技術與工具

Accessibility / UX / Eye-tracking Interface / iPadOS

## 參與背景與需求

在實踐大學 USR「科技生活設計跨領域大工作營（一）之智慧照護設計」參與第四組，完成 54 小時工作營。團隊針對無法以口語或肢體順利表達的使用者，提出以 iPadOS 情境為基礎的眼控介面設計。

## 互動設計

規劃放大選取區域與增加間距，以降低誤選；使用九宮格鍵盤、常用語、直覺頁面切換及緊急呼叫，協助不同情境下的訊息表達。另提出 AI 個人助理功能構想，並以海報與專刊整理成果。

## 成果與角色

2025/11/19 第四組獲金秀獎，楊善茵列名於獎狀與工作營證明。這是跨域團隊設計成果；未提供個人實作分工、可部署軟體或臨床測試，不宣稱已完成 AI 助理產品。

## 履歷重點

- 參與實踐大學「科技生活設計跨領域大工作營（一）之智慧照護設計」，與跨領域團隊共同提出 EyeAble 眼控介面設計。

- 團隊針對無法以口語或肢體表達的使用者，提出放大選取區域、增加間距、九宮格鍵盤及直覺頁面切換等設計。

- 成果涵蓋常用語、緊急呼叫與個人助理概念，完成海報及專刊展示，團隊於 2025/11/19 獲金秀獎；個人完成 54 小時工作營。
