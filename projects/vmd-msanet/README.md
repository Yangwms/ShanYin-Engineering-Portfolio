# 台股預測與策略回測

**VMD-MSANet · 聯發科 2454.TW**

16 個 VMD 特徵 · 單日與五日預測方法比較

[返回作品集首頁](../../README.md)

## 技術與工具

Python / yfinance / vmdpy / Attention / Multi-task Learning

## 研究問題與資料

以聯發科 2454.TW 為標的，研究多尺度特徵與不同預測目標在歷史策略回測中的表現。透過 yfinance 整合 2018 年起 OHLCV、台灣加權指數、0050、美國市場指數及美元／新臺幣匯率。

## 特徵建構與工程處理

對 5、10、20、30 日尺度各取 4 個 VMD IMF，形成 16 個分解特徵，搭配注意力模型。處理 vmdpy 輸出序列長度對齊，並在研究流程中考慮因子延遲、訊號與報酬對齊。

## 兩種研究方法

| 面向 | 單日報酬預測 | 五日報酬及上漲機率雙任務 |
| --- | --- | --- |
| 預測目標 | 下一日報酬 | 未來五日報酬與上漲機率 |
| 研究設定 | 單日預測與策略回測 | 加入技術指標與驗證集門檻搜尋 |
| 回測交易日 | 344 | 343 |
| 累積報酬 | 29.54% | 43.04% |
| 年化報酬 | 20.88% | 30.08% |
| Sharpe Ratio | 0.9817 | 1.2100 |
| 最大回撤 | -19.13% | -15.32% |
| 方向準確率 | 45.06% | 48.10% |

## 解讀與限制

兩者為不同預測目標與程式設定的研究比較，不視為產品版本或單一變因下的效能升級。回測自 2025/01 起，報告截至 2026/06；使用逐日滾動方式，訊號變化時扣除 0.1425% 設定成本。五日方法仍落後同期大盤與 0050，結果不能視為真實獲利或未來報酬保證。原研究報告保留原始記錄，首頁及本頁以方法名稱呈現。

## 履歷重點

- 串接資料擷取、特徵建構、模型訓練與逐日滾動回測；整合 2018 年起個股、市場指數與匯率資料。

- 以 5／10／20／30 日尺度各分解 4 個 IMF，建立 16 個 VMD 特徵，並處理 vmdpy 序列長度對齊問題。

- 比較單日報酬預測與五日報酬／上漲機率雙任務方法；五日方法加入技術指標及驗證集門檻搜尋，研究回測報酬 43.04%、最大回撤 -15.32%，並與市場基準比較。

## 成果文件與程式狀態

回測自 2025/01 起，報告資料截至 2026/06；單日與五日方法分別為 344／343 個交易日。訊號變化時扣 0.1425% 設定成本。五日方法 Sharpe 1.21、方向準確率 48.10%，仍落後同期大盤及 0050；非實際投資獲利。
