## 技術與工具

Python / Django / PostgreSQL / SQL / HTML / CSS / Bootstrap / Azure

## 問題與目標

面對分散的市場資訊與財報指標，團隊以網站整合資料蒐集、清理、指標計算及選股介面，協助使用者依產業與財務條件檢視標的。此為大學畢業專題，楊善茵為簡報列名之團隊成員；各模組未提供個人分工比例。

## 系統架構

| 層次 | 使用技術 | 專題功能 |
| --- | --- | --- |

| 執行環境 | Azure VM、crontab | 網站／資料庫部署與定期更新 |

## 資料管線與工程處理

以 2015 年起的股票資料及將近十年財報為基礎，清理後存入 PostgreSQL。團隊將連線、建表、插入、查詢及日期轉換等常用操作模組化，並使用 psycopg2 進行建表與批次插入。實作中特別處理未上市、已下市標的的資料對齊與缺值；市場資料透過 crontab 排程更新。

## 主要功能

- **ETF 排行**：以近 30 日平均日報酬率排序，呈現前 30 名並提供篩選／排序介面。
- **財務指標篩選**：依產業與 EPS、ROE、ROA、FCF 等條件查詢標的。
- **因子排名**：整理基本面與衍生因子，使用條件篩選、權重／分數排名及 Z-score 閾值處理極端值。
- **財報智選**：根據問卷回答計算風險分數、分類風險屬性，再對應股票推薦。

## 成果與後續方向

團隊另進行兩組兩年期歷史回測：2019/06/22–2021/06/22 組合報酬 105.14%（大盤 77.79%）；2022/01/22–2024/01/22 組合報酬 14.9%（大盤 -1.83%）。簡報未完整揭露成本與偏誤控制，僅保留作為研究紀錄，不視為實際獲利或未來績效。

簡報提出個人清單、投資組合回測與更多 Azure 服務作為後續方向；這些屬未來規劃，不列為已完成功能。

## 履歷重點

- 參與團隊建置投資資訊網站，以 Django 處理後端邏輯，搭配 HTML、CSS、Bootstrap 介面及 PostgreSQL 資料庫，整合市場交易、財務報表與產業分類資料。

- 團隊建置 26 張資料表，將資料庫連線、建表、批次插入與查詢作業以 Python 模組化；使用 yfinance、Selenium 與 crontab 支援資料擷取及排程更新。

- 成果涵蓋 ETF 排行、財務指標篩選、因子排名與風險問卷選股；使用 Microsoft Azure 虛擬機器部署網站與資料庫。
