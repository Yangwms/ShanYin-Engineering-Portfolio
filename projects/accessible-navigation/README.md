## 技術與工具

A* / CNN / MDP / Reinforcement Learning / Autoencoder / Accessibility

## 課程與需求分析

人工智慧課程提案。傳統最短路徑可能將使用者帶入擁擠區域，且無法即時應對施工、封路與突發事件，因此以視障者的可跟隨性與風險提示為設計核心。

## 架構與方法分工

| 模組 | 提案方法 | 預期責任 |
| --- | --- | --- |
| 環境建模 | 節點與加權路徑 | 表示路段、靜態成本與風險 |
| 初始路徑 | A* | 依成本產生初始規劃 |
| 視覺感知 | CNN | 感知人流與環境風險 |
| 策略選擇 | MDP／強化學習 | 在改道、繼續前進或等待之間決策 |
| 異常預警 | Autoencoder | 依重建誤差辨識偏離正常場景的狀況 |
| 使用者回饋 | 語音與震動 | 輸出方向、風險及替代路線提示 |

## 視障友善設計

規劃降低有導盲磚、牆邊或欄杆路段的成本，以優先選擇較易跟隨的路線。前方出現障礙物或人潮時，提供提前語音提示；在人潮湧入情境下，也考慮短暫等待，而非一律改道。簡報以不同震動模式傳達左右轉，這些都是介面與互動構想。

## 異常偵測構想

使用正常場景影像訓練 Autoencoder，再以輸入影像與重建影像之間的誤差作為異常線索。提案以跌倒、通道阻擋、推擠或人潮驟變為例，規劃提高區域風險成本並發出警示；未提供已訓練模型、閾值或辨識實驗。

## 限制與驗證需求

簡報指出 GPS 在室內較弱、視覺遮擋、夜間與新場域效能下降等問題，提出 Beacon、QR、Wi-Fi 指紋、多源定位及容錯設計方向；亦討論邊緣運算、去識別化或僅回傳統計特徵。以上屬提案中的設計考量，尚待實作與使用者驗證。

## 履歷重點

- 針對視障者在校園、車站等場域的移動需求，提出以加權圖表示路段、以 A* 規劃初始路徑的系統架構，將擁擠、封路與障礙風險納入成本更新。

- 規劃 CNN 視覺感知、MDP／強化學習策略決策與 Autoencoder 重建誤差預警，連結改道或等待策略及語音、震動提示；整理室內定位、遮擋與跨場域泛化限制。
