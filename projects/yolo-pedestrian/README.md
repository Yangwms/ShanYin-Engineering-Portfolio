## 技術與工具

Python / OpenCV / YOLO / Object Detection

## 課程與問題背景

多媒體資料檢索與處理課程。以行人作為目標類別，探討物件偵測如何同時輸出類別與位置，並將模型推論結果轉換為可直接觀看的影像標註。

## 處理流程

1. 以 Python／OpenCV 取得影像輸入。
2. 呼叫 YOLO 預訓練模型進行物件偵測。
3. 篩選 Person 類別。
4. 繪製 Bounding Box 與標籤。
5. 比較原始影像與偵測畫面，整理可辨識情境及限制。

## 成果與應用發想

簡報包含原始畫面與行人框選畫面的對照，以視覺化方式展示定位結果。提出校園上下課尖峰、車站候車區／月台／出入口作為應用情境；這些是可能使用場域，不代表已完成現場部署。

## 限制與延伸

低光源、遠距離及遮擋會影響辨識。現有範圍為行人偵測，尚未包含跨影格追蹤、行為辨識或人流統計。後續可探索追蹤與人流分析；未提供模型版本、FPS、準確率或自行訓練紀錄，不補填這些數值。

## 履歷重點

- 以 Python 與 OpenCV 串接攝影機影像及 YOLO 預訓練模型，篩選 Person 類別，在畫面中繪製行人邊界框與標籤。

- 完成原始畫面與偵測結果展示，整理低光源、遠距離與遮擋情境的限制；目前功能為行人偵測，尚未包含追蹤與行為分析。
